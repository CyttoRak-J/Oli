Troubleshooting

Common issues and how to fix them.

My theme, queue, and history reset after an update

Oli stores everything in a single database file. If an earlier update was interrupted (for example the app was closed while copying its data), the database could fail its integrity check and start over with a fresh one.

Oli now automatically restores missing data from the previous app data folder on its next launch, and the copy is done in a way that can no longer be corrupted. Your settings, queue, history, favorites, and playlists come back — anything you changed in the meantime is kept.

Pasting a YouTube link does nothing

Open the Search page, paste the link, and press Enter. A panel appears with download options:

  • Both video + playlist links (e.g. watch?v=...&list=...) offer a choice: This video only or Entire playlist.
  • Video-only links offer Song (tagged audio) or Video downloads.
  • Playlist-only links download the whole playlist as songs.

Downloads fail or never start

Oli bundles yt-dlp inside the app. If downloads fail, check that:

  • You are online and YouTube is reachable.
  • You chose a destination folder you have write access to.
  • The file resources\bin\yt-dlp.exe exists inside the installation folder (reinstall if it is missing).

For video downloads, ffmpeg is needed. Oli uses the ffmpeg already installed on your system — install it with winget install ffmpeg if video downloads fail.

Oli does not resume the last played song

Resume on launch works with the current build: the song and position are saved while you listen. Make sure Settings → Playback → Resume on launch is enabled. If the song came from YouTube it must still be online when Oli starts.

My library is empty after updating

Open Settings → Library and confirm your music folder is still listed, then run a rescan. If the folder is gone, add it again — Oli re-imports all files. Your playback history, queue, and favorites are stored separately and are not affected.

Finding the log files

If something goes wrong, the log file usually explains what happened. Logs are stored in: 

%APPDATA%\Oli\logs

The most recent file is named cytto-<date>-<time>.log. When reporting an issue, attach the newest log file — it includes the full story of what the app did.

Backing up your data

Everything Oli knows lives in one SQLite database. To back it up, copy:

%APPDATA%\Oli\library.sqlite

Keep a copy somewhere safe. To restore, close Oli and put the file back in that folder, replacing the current one.

Only restore a backup created by a recent Oli version — older database formats are upgraded automatically, but a backup from the far past may be missing newer features.
